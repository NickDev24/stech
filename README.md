# 🚖 STECH — Plataforma de Movilidad Urbana Inteligente

> **STECH** es una plataforma integral de movilidad urbana y viajes compartidos (remises, taxi compartido, carpool urbano) con gobernanza municipal incorporada. Diseñada para la Ciudad de Salta, Argentina — escalable a cualquier ciudad.

---

## 🎯 Qué es STECH

STECH conecta **pasajeros** con **conductores** (remises y taxis) mediante un algoritmo propio de viajes compatibles, con tarifas dinámicas por franja horaria, pagos digitales, billetera interna y herramientas de regulación municipal que **ninguna otra plataforma ofrece**.

### Función social
- 🏙️ **Movilidad accesible**: transporte compartido que baja el costo por viaje
- 🚓 **Seguridad vial**: verificación de habilitaciones vehiculares con QR escaneable por la policía
- 📊 **Gobernanza municipal**: datos en tiempo real para la autoridad de transporte
- 🛟 **Emergencias**: botón de pánico geolocalizado (Ordenanza 16.377)
